# Trackpad Numpad

Mac 트랙패드의 터치 위치를 숫자 키패드로 바꾸는 macOS 메뉴 막대 앱입니다. Swift와 AppKit/SwiftUI로 작성했으며 외부 패키지 의존성이 없습니다.

## 실행

설치된 앱: `/Applications/Trackpad Numpad.app`

다시 빌드할 때 생성되는 앱: `dist/Trackpad Numpad.app`

1. 응용 프로그램 폴더의 앱을 실행합니다. 별도 설정 창 없이 메뉴 막대에서 대기합니다.
2. 메뉴 막대의 **손쉬운 사용 권한 허용…**을 눌러 시스템 설정 → 개인정보 보호 및 보안 → 손쉬운 사용에서 **Trackpad Numpad**를 허용합니다. 목록에 없으면 `+`로 앱을 추가하세요.
3. 메모나 스프레드시트 등 숫자를 입력할 앱의 입력 칸을 선택합니다.
4. **오른쪽 Command + 오른쪽 Option**을 함께 눌러 켠 뒤 키를 놓습니다. 왼쪽 키 조합이나 추가 Shift/Control 조합은 활성화하지 않습니다. 같은 단축키로 다시 끌 수 있으며 누르고 있어도 반복 실행되지 않습니다. 트랙패드 전체가 아래 배치의 숫자판이 됩니다.
5. 원하는 칸을 한 손가락으로 짧게 탭하고 뗍니다. **Esc** 또는 같은 오른쪽 단축키로 끕니다.

```text
┌─────┬─────┬─────┬─────┬─────┐
│  ⌫  │  ÷  │  7  │  8  │  9  │
├─────┼─────┼─────┼─────┼─────┤
│  ×  │  −  │  4  │  5  │  6  │
├─────┼─────┼─────┼─────┼─────┤
│     │     │  1  │  2  │  3  │
│  +  │  ↵  ├─────┴─────┼─────┤
│     │     │     0     │  .  │
└─────┴─────┴───────────┴─────┘
```

트랙패드 모양의 짙은 반투명 블러 오버레이에 버튼, 손가락 위치, 입력 키 강조와 작은 `Esc로 해제` 문구만 표시합니다. 메뉴 막대의 **키 배치 미리 보기**로 배치를 확인할 수 있습니다. 가로 5등분, 세로 4등분이며 `0`, `+`, `Enter`는 두 칸 크기입니다.

25~450ms의 짧은 탭을 손가락을 뗄 때 한 번 입력하며 입력용 손가락을 대서 탭이 시작될 때 햅틱 한 번, 뗀 뒤 유효한 입력으로 확정될 때 한 번을 줍니다. 머무는 동안 반복하지 않고, 취소된 탭의 해제 시점에는 확정 햅틱을 주지 않습니다. 접촉한 채 이동하여 `5`의 작은 중앙 영역에 들어갈 때와 나갈 때 위치 안내 햅틱을 각각 한 번 줍니다. 진입 경계는 한 키 크기의 반지름 12%, 이탈 경계는 18%인 타원으로, 경계에서 조금 흔들려도 반복하지 않습니다. 손가락을 떼는 것은 이탈 햅틱을 발생시키지 않습니다.

한 손가락을 약 120ms 이상 가만히 두면 위치와 관계없이 기준 손가락으로 인식하여 다른 손가락으로 반복 탭할 수 있습니다. 손가락을 댄 채 활성화한 경우도 지원합니다. 동시에 두 손가락을 대는 경우에는 `5` 중앙의 손가락을 즉시 기준으로 선택합니다. 기준 손가락은 숫자를 입력하지 않습니다. 기준 손가락이 떨어지거나 원래 위치에서 정규화 거리 0.08 이상 움직이면 진행 중인 탭을 취소하고 모두 뗀 뒤 다시 시작합니다. 기준 손가락 없이 단독으로 `5`를 탭하면 정상적으로 숫자 5를 입력합니다. 기준 손가락 외에 두 손가락 이상을 동시에 대거나 밀기·길게 누르기를 하면 그 탭을 취소합니다.

물리적으로 누른 마우스 클릭은 통과시키며 해당 클릭에 숫자 입력이 겹치지 않게 현재 탭을 취소합니다. 클릭의 누름·드래그·뗌을 한 쌍으로 처리합니다. 트랙패드 터치 중이거나 직후 250ms 이내인 압력 0의 클릭은 탭하여 클릭하기로 판단하여 차단합니다. 이 구분은 압력과 접촉 시점에 의존하므로 장치별 실제 동작 확인이 필요합니다. 압력이 없는 외장 마우스를 트랙패드와 동시에 사용하면 탭 클릭으로 분류될 수 있습니다. 일반 포인터 이동·스크롤은 계속 차단하고 물리 클릭 드래그는 통과시킵니다.

일반 키보드는 계속 사용할 수 있습니다. 절전 진입, 감시 중단, 권한 철회 및 보안 입력 감지 시 모드를 해제합니다. 다시 실행하면 꺼진 상태로 시작합니다.

## 설정 및 실험적 보정

메뉴 막대 아이콘 → **설정…** → **일반** 탭에서 조작키를 왼쪽 또는 오른쪽으로 배치할 수 있습니다. 기본은 왼쪽이며 변경은 자동 저장됩니다. 설정창을 열면 숫자판을 해제하여 설정을 조작할 수 있습니다.

일반 탭의 **다시 켤 때 보정 유지**는 기본적으로 켜져 있습니다. 켜면 오른쪽 Command+Option으로 껐다 켜도 마지막 보정을 이어 씁니다. 끄면 다음 활성화부터 기본 배치로 시작하며 필요하면 다시 보정할 수 있습니다. 저장된 보정 자체를 삭제하는 옵션은 아니며 메뉴·Esc로 끈 뒤 켜는 경우와 앱 재실행 후 활성화에도 같은 정책을 적용합니다.

**실험적** 탭의 **손가락 위치로 좌표 보정**은 기본적으로 꺼져 있습니다. 켠 뒤 설정창을 닫고 숫자판을 활성화하세요. 기존 접촉을 모두 뗀 다음 세 손가락을 동시에 짧게 탭하면 왼쪽부터 **4·5·6**을 기준으로 전체 배치를 이동·회전하고 균일하게 확대·축소합니다. 키 모양과 비율을 유지하면서 세 손가락과 키 중앙의 거리 제곱합이 가장 작아지도록 맞춥니다. 손가락 간격이 고르지 않으면 세 점 모두에 정확히 일치하지는 않으며 가장 가까운 배치를 사용합니다. 세 손가락이 일직선이어도 사용할 수 있습니다.

그 아래 **4손가락 보정 추가**를 별도로 켤 수 있습니다. 네 손가락을 동시에 탭하면 왼쪽에서 두 번째와 세 번째 접촉점을 **삭제·÷**의 기준점으로 사용합니다. 두 점을 기준으로 이동·회전·균일한 크기 조절을 적용하여 두 키 중앙을 손가락 위치에 맞춥니다. 4손가락 옵션은 실험적 보정이 켜져 있을 때만 동작합니다.

마지막 3/4손가락 보정이 전체 숫자판에 적용됩니다. 보정에 쓰인 탭은 숫자를 입력하지 않습니다. 물리 클릭으로도 현재 세/네 접촉점을 보정할 수 있으며 물리 클릭 자체는 계속 통과합니다. 접촉 시작 간격은 120ms 이내, 전체 탭은 25~450ms, 이동은 트랙패드 정규화 거리 0.035 이내여야 합니다. 보정 후 오버레이 버튼도 실제 터치 위치에 맞춰 이동·회전·균일한 크기 조절을 적용합니다. 일부 키가 트랙패드 밖으로 나갈 수 있으므로 필요한 경우 다시 보정하거나 **보정 초기화**를 사용하세요.

보정은 조작키 방향별로 따로 저장됩니다. 이전 3·5·6 또는 회전·이동 전용 보정은 적용하지 않으므로 새 4·5·6 기준으로 다시 보정하세요. 실험적 기능을 끄면 저장한 보정은 유지하면서 기본 좌표로 돌아갑니다. **보정 초기화**는 현재 방향의 보정만 지웁니다.

## 개발

macOS 13 이상, Swift 5.9 이상이 필요합니다. 앱 빌드는 현재 Mac 아키텍처를 대상으로 합니다.

```sh
swift test
bash scripts/build-app.sh
"dist/Trackpad Numpad.app/Contents/MacOS/TrackpadNumpad" --diagnose
```

`--diagnose`는 프레임워크/기본 트랙패드와 권한 상태를 확인하고 터치 수신 시작·종료를 검사합니다. GUI 없이 실행되며 권한을 요청하지 않습니다. 터치 수신 시작 성공만으로 실제 탭 입력이나 다른 앱으로의 키 전달까지 검증되는 것은 아닙니다. `--settings`는 설정창을 열어 시작합니다. `--smoke-test`는 오버레이를 띄운 후 2초 뒤 종료하는 UI 확인 옵션입니다.

## 구현 및 제약

- `CTrackpad`: `dlopen`으로 MultitouchSupport를 열고 기본 트랙패드의 정규화된 절대 터치 좌표를 수신합니다. 장치 선택·핫플러그는 지원하지 않습니다. 트랙패드 연결 변경 후 앱을 재실행하세요.
- `TrackpadCore`: 좌표 → 키 매핑, 손가락 ID·이동량·접촉 시간·동시 접촉을 확인하는 탭 판정. 테스트에는 전체 키 배치, 반복 탭, 스와이프 취소, 다중 접촉, 잘못된 좌표와 해제 시 상태 초기화를 포함합니다.
- `TrackpadNumpad`: 오른쪽 물리 보조 키를 구분하는 CGEvent 단축키, CGEvent 입력 제어, 메뉴 막대, 비활성 트랙패드 오버레이. 숫자는 실제 숫자 키패드의 가상 키 코드로 전달하므로 앱의 키 바인딩과 소수점/언어 설정에 따라 해석될 수 있습니다.
- 터치 좌표는 **Apple 비공개 API**를 사용합니다. 향후 macOS에서 호환성이 바뀔 수 있으며 App Store 배포를 대상으로 하지 않습니다. API 로드나 장치 시작 실패 시 모드를 켜지 않습니다. 앱 샌드박스는 사용하지 않습니다.
- 배포 스크립트는 로컬 실행용 임시 서명을 합니다. Apple 공증이나 Developer ID 서명은 포함하지 않습니다. 빌드나 위치를 변경한 뒤 권한이 동작하지 않으면 손쉬운 사용 목록에서 앱을 제거하고 다시 추가하세요.
- 네트워크 접근이나 입력 기록 파일 저장 기능은 없습니다. 입력 키 강조와 접촉 위치만 화면에 표시합니다.

API 참고: [OpenMultitouchSupport](https://github.com/Kyome22/OpenMultitouchSupport), [Multitouch ABI](https://github.com/ZaynJarvis/trackpad-studio/blob/master/Sources/CMultitouchShim/include/CMultitouchShim.h), [Apple CGEvent](https://developer.apple.com/documentation/coregraphics/cgevent).

햅틱은 Force Touch 트랙패드에서 지원됩니다. 손가락을 뗀 뒤에도 피드백을 주기 위해 MultitouchSupport의 액추에이터를 사용하며, 사용할 수 없는 경우 AppKit 햅틱으로 대체합니다. `--test-haptic`으로 짧은 진동 한 번과 드라이버 반환 상태를 확인할 수 있습니다. API 참고: [액추에이터 호출 예제](https://gist.github.com/niw/b120b460e854ec10cefeeb60784f5dbb), [Apple 햅틱 API](https://developer.apple.com/documentation/appkit/nshapticfeedbackperformer).
